# 🐝 Task-Hive — Scalable, Modern Task Service Platform Built with MERN ⚡

**Task-Hive** is a full-stack service provider platform that connects users with skilled local professionals — from electricians to cleaners to handymen. Designed with extensibility and modularity at its core, Task-Hive empowers developers to improve and scale the project into a robust service marketplace.

🛠️ **Built Entirely with the MERN Stack** — React.js, Node.js, Express.js, and MongoDB.

---

## 🚀 Why Task-Hive?

- 🔍 Book trusted service providers quickly and securely  
- 📱 Optimized for modern browsers and mobile devices  
- 🔐 Secure user authentication & route protection with JWT  
- 🧱 Modular code structure, built for rapid iteration  
- 🧠 A developer-friendly codebase ready for scaling

> 💡 **Task-Hive is more than a project — it's an open-source base for a full-featured task marketplace, ideal for collaboration and extension by MERN developers.**

---

## 🧰 Tech Stack

| Layer       | Tech                    | Description |
|-------------|-------------------------|-------------|
| ⚛️ Frontend | React.js + Context API  | Reusable components, fast UI rendering |
| ⚙️ Backend  | Node.js + Express.js    | REST API with route & controller separation |
| 🛢️ Database | MongoDB + Mongoose      | Schema-rich NoSQL database |
| 🔐 Auth     | JWT + Bcrypt.js         | Secure login & role-based access |
| 💅 Styling  | Tailwind CSS            | Clean, utility-first design |

## 🛠️ Local Setup

```bash
# 1. Clone the repo
git clone https://github.com/your-username/task-hive.git

# 2. Backend setup
cd backend
npm install
touch .env # Add MongoDB URI, JWT secret, etc.
npm run dev

# 3. Frontend setup
cd ../frontend
npm install
npm start
